Để hoàn thành dự án Compliance Report System (Mini) trong vòng 2 ngày và sẵn sàng cho buổi phỏng vấn tại Mobile Oasis, đây là danh sách các công việc quan trọng được chia theo lộ trình "Sprint":

🟢 GIAI ĐOẠN 1: Nền tảng & Backend (Ngày 1 - Buổi sáng)
Thiết lập cấu trúc thư mục: Tạo các folder Backend, AI_Service, Frontend, và db-init.

Khởi tạo Database: * Viết file init.sql để tạo bảng và chèn dữ liệu mẫu (Seed data).

Viết docker-compose.yml cho PostgreSQL.

Xây dựng .NET 9 API:

Tạo Project Web API.

Định nghĩa Model (Document, Report) và ApplicationDbContext.

Viết UploadController: Xử lý nhận file, lưu file vào thư mục và lưu thông tin vào DB.

🟡 GIAI ĐOẠN 2: Trí tuệ nhân tạo & Logic AI (Ngày 1 - Buổi chiều)
Xây dựng Python AI Service:

Tạo FastAPI app.

Viết Prompt Engineering (mẫu JSON output).

Kết nối OpenAI API để nhận text và trả về kết quả phân tích.

Kết nối .NET ↔ Python:

Dùng IHttpClientFactory trong .NET để gọi sang Python Service sau khi upload file thành công.

🔵 GIAI ĐOẠN 3: Frontend & Giao diện (Ngày 2 - Buổi sáng)
Xây dựng Dashboard:

Cài đặt React + Tailwind CSS + Lucide React (icons).

Hiển thị danh sách báo cáo với các Badge màu sắc (Compliant, Warning, Non-Compliant).

Xây dựng Trang chi tiết (Report Detail):

Hiển thị các Issue cụ thể, điểm số và trích dẫn luật từ AI.

🟠 GIAI ĐOẠN 4: Đóng gói & Hoàn thiện (Ngày 2 - Buổi chiều)
Containerization (Docker):

Viết Dockerfile cho .NET API.

Viết Dockerfile cho Python AI Service.

Hoàn thiện docker-compose.yml để chạy toàn bộ hệ thống bằng 1 lệnh.

Kiểm thử Happy Path: Chạy thử luồng: Upload file -> Chờ xử lý -> Xem kết quả trên Dashboard để đảm bảo không có lỗi demo.

🔴 GIAI ĐOẠN 5: Chuẩn bị phỏng vấn (Trước giờ G)
Hoàn thiện Slide: Chèn các ảnh chụp màn hình code và giao diện vào slide.

Luyện tập kịch bản nói: Nói thử ít nhất 3 lần dựa trên kịch bản đã soạn để trôi chảy và canh thời gian (5-7 phút).

Ôn tập Q&A: Tự trả lời các câu hỏi về bảo mật dữ liệu, xử lý lỗi AI và lý do chọn kiến trúc Microservices.
